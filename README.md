## 👋 Hi, I'm Anand

I like building things that sit between hardware and software: sensors, boards and radios on one side, backend services and AI on the other.

> **In plain words:** a camera reads a number plate, a tag is scanned, a scale weighs something, and a gate opens on its own while someone watches it happen live on a screen. Making that whole chain reliable is the kind of problem I enjoy, from the wire to the dashboard. These days I'm also teaching it to run AI on tiny boards, with no cloud needed.

Most of what's here started as *"I wish this existed"* or *"I want to run this myself"*. That's how I ended up with self-hosted tools, MCP servers that let AI assistants manage my homelab safely, and Android apps I use every day.

## 🧪 My homelab

The place where I break things on purpose:

- **Compute:** 6× Proxmox hosts (4-node SBC cluster plus 2 mini PCs) running Docker and LXC
- **AI:** Mac mini M4 and Radxa ROCK boards (RK3588 / RK3576 NPU) for local LLMs, OCR and speech
- **Storage & network:** CM3588 NAS on TrueNAS, with OpenWrt routing
- **Observability:** Beszel, Gotify and Home Assistant, plus my own MCP servers so AI can help operate it
